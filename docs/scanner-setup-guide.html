Scanner Registration Flow

Overview: This guide covers the complete process of registering a new branch scanner with ASTRA CTS — from generating a one-time code at bank headquarters to the scanner agent going live on the teller PC. The entire setup takes under 10 minutes. The branch IT coordinator enters only 2 fields.

Phase 1
Generate Registration Code
Ops Manager · Bank HQ
1
Open Branch Master
Navigate to Admin → Branch Master. Locate the target branch. Confirm Scanner Mode is SDK_PUSH and Status is Active. Branches in FOLDER_DROP or UI_UPLOAD mode do not get a scanner token.
2
Click the Register Scanner icon (🔑)
A key icon appears on every row where Scanner Mode = SDK_PUSH. Click it to open the Registration panel for that branch.
3
Click "Generate Registration Code"
The ASTRA server creates an 8-character one-time code tied exclusively to this branch. A 24-hour countdown starts immediately. The code appears in large monospace type — easy to read over the phone.
🔐 Only one active code per branch at a time. Generating a new code automatically invalidates any previous pending code for this branch.
📞
Handoff
Secure Code Delivery
Ops Manager → Branch IT
4
Read the code to the Branch IT Coordinator
Call the branch IT coordinator and read the 8-character code aloud (e.g. "SARAS-3X7Q"). Alternatively use your bank's secure internal messaging system. Do not send via plain email or SMS.
🔐 The code expires in 24 hours and is single-use. Even if intercepted, it only works for the exact branch it was generated for — branch identity is server-authoritative.
💻
Phase 2
Run Installer at the Branch
Branch IT Coordinator · Teller PC
5
Obtain the installer from IT portal
Download ASTRA-Scanner-Setup-v{version}.exe from the bank's internal software portal. Verify the SHA-256 checksum matches before running. The installer is built once in CI and deployed to all branches — no branch-specific build needed.
6
Run installer as Windows Administrator
Right-click the .exe → "Run as administrator". Accept the UAC prompt. The installer requires admin rights to install the Windows service and set token.dat file permissions.
7
Enter exactly 2 fields
The installer wizard shows only two input fields: (1) ASTRA Server URL — same for all branches in your bank, provided by bank IT; (2) Registration Code — the 8-character code from Ops Manager.
🔐 No branch name, no branch ID, no region — these are returned by the server and cannot be overridden. This prevents any branch from impersonating another.
8
Click "Verify →"
The installer contacts the ASTRA server, submits the code and the PC's machine name, and receives all branch configuration automatically. A green tick confirms a successful exchange.
⚡
Automatic
Server-Side Exchange
ASTRA Platform · No human action
9
Code atomically consumed from Redis
The server executes a single atomic GETDEL on the Redis key scanner_reg:{bank_id}:{code}. The code is gone the instant it is read — it cannot be replayed.
🔐 Atomic single-use: even if the network request arrives twice simultaneously, only one exchange succeeds. The second attempt receives 401.
10
Branch config loaded & machine-bound token issued
Server reads branch details (branch_id, IFSC, endorsement settings, UV scan flags) from YugabyteDB and generates a random API token bound to COMPUTERNAME of this PC — it will not authenticate from any other machine.
11
Full config returned to installer
Response: branch_id, bank_id, bank_ifsc, api_url, endorsement_text, enable_imprinter, enable_uv_scan, and the raw API token (shown only once — never stored on the server).
✅
Phase 3
Scanner Goes Live
Installer → Windows Service → Teller PC
12
config.ini written to installation folder
Non-secret configuration is saved: server URL, branch_id, IFSC, scan settings. This file can be read by any Windows user — it contains no credentials.
13
token.dat written with restricted NTFS permissions
The API token is saved to token.dat. The installer immediately restricts NTFS permissions: Read/Write for SYSTEM and Administrators group only. Standard user accounts (including the teller login) cannot read this file.
🔐 Even if a teller's Windows account is compromised, the attacker cannot extract the scanner token. Only the service (running as SYSTEM) can read it.
14
ASTRAScannerAgent service installed and started
The installer registers ASTRAScannerAgent as a Windows service set to Automatic (start on boot). The service starts immediately. On the Branch Scan Monitor, the branch shows as "Connected" within seconds.
15
✅ Scanner Operational — Teller can begin
Load cheques into the Canon CR-120 / CR-150 feeder. Each cheque is automatically captured (front + back image, hardware MICR), UV scanned, and submitted to ASTRA CTS. Real-time status appears in the Branch Scan Monitor.
Security design — why it is safe
🔒
Branch ID is server-authoritative
The IT coordinator enters zero branch identity. The server returns it. No forgery possible.
⚡
Single-use code (atomic)
Redis GETDEL — code vanishes on first successful exchange. No replay window.
🖥️
Machine-bound token
Token stored with machine_id = COMPUTERNAME. Fails authentication on any other PC.
🛡️
token.dat unreadable by users
NTFS ACL: SYSTEM + Administrators only. Standard teller account cannot read it.
⏰
24-hour code expiry
Unexchanged codes auto-expire from Redis. No dangling codes after installation window.
🔑
One active code per branch
Generating a new code invalidates the previous one. No duplicate registrations.

Common issues
?
"Invalid code" error on Verify
Code has already been used, or has expired (24h limit). Ask Ops Manager to generate a new code from Branch Master.
?
Installer says "Branch not eligible"
Check that the branch Scanner Mode is set to SDK_PUSH in Branch Master. FOLDER_DROP and UI_UPLOAD branches do not get a token.
?
Service installs but scanner shows Disconnected
Check firewall: outbound HTTPS (port 443) to the ASTRA server URL must be allowed from the teller PC. Also verify the Canon scanner USB driver is installed.
?
Need to re-register (PC replaced / token expired)
Ask Ops Manager to generate a fresh code from Branch Master. Run the installer again — it will revoke the old token automatically and issue a new one for the new machine.
