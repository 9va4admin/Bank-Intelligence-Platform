ASTRA
Automated Settlement and Transaction Recognition Architecture
Precision banking platform for Indian banks. Three independent AI-powered modules — CTS (Cheque Truncation), EJ (ATM Electronic Journal), and MSV (Multi-Signature Validation) — unified on shared infrastructure. On-premises deployment, zero cloud dependency, RBI compliant. Gemini-hardened architecture (July 2026).

Three-Module Architecture
🏦
CTS Module
Cheque Truncation System
One AI agent per inward cheque. Solves RBI T+3-hour IET mandate (Jan 2026). 500 cheques → 500 parallel Temporal workflows → entire batch <600ms wall clock. Vision LLM for alteration detection, Siamese network for signature verification, XGBoost for fraud scoring. Outward: CTS-2010 image quality + MICR + signature-present check. Inward: sig vault match + fraud score + CBS + IET guard.
₹71L cr / year cleared 609M cheques (FY25) 18-month first-mover window IET watchdog at T−30s Qwen2-VL 72B · GOT-OCR2 · XGBoost YOLOv8 sig detector (port 8020)
🏧
EJ Module
ATM Electronic Journal Intelligence
AI normalisation of Electronic Journal logs across all ATM OEMs. 5+ OEMs (NCR, Diebold, Wincor, Nautilus, GRG), zero standard format — LLM solves this permanently. Dispute resolution with CCTV evidence correlation, fleet observability, predictive maintenance. Now with EJ integrity check (9th activity) and reconciliation orphan scanner.
2.5L+ ATMs deployed 5+ OEMs, zero standard Llama 3.3 70B parser BGE-M3 dispute matching Go edge agent at branch 9th activity: integrity check
✍️
MSV Module NEW
Multi-Signature Validation
Joint-account and mandate-driven signature validation. BRE engine evaluates signatory rules (AND/OR/MAJORITY patterns). Signatory registry vault for specimen management. Bulk enrollment with progress tracking. Fully isolated from CTS and EJ — separate Temporal task queues, separate DB schema, separate Redis namespace.
BRE engine: AND/OR/MAJORITY Siamese net per signatory BGE-M3 embeddings MSVWorkflow + 6 activities Bulk enrollment + tracker
