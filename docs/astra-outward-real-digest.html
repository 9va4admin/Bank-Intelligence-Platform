Defects found and fixed to get here (all with tests, all committed)

  • Lenient asyncpg DATE codec — ~15 API queries binding an ISO date string to a DATE column raised inside a swallowed try/except (outward lots list silently returned []).
  • cts.cheque_instruments had no storage partitions from 2026-09-01 onward — every insert, inward AND outward, was failing platform-wide.
  • Outward accepted scans wrote only a masked cts.outward_scan_events row — no full instrument record, no lot assignment. New persist_outward_instrument activity + migration.
  • MICR OCR text (plain digit groups, bank-name prefixes) wasn't parseable by the symbol-based validator — added an anchored fallback parser; unparseable MICR now holds for human repair instead of erroring or fabricating data.
  • Endorsement: EndorsementTemplate constructor mismatch, missing fetch_instrument_images, and the stamper never actually stamped the image — all real, none previously exercised.
  • LotStore was wired to the async MinIO wrapper instead of the raw client it needs; scan images live in a different bucket than the lot store's own, so image keys weren't bucket-qualified.
  • ClearingSessionWorkflow looked up lots by a caller-invented session id no lot ever carried, and by the wrong status — always found zero lots. Rebuilt around (bank_id, clearing_date, pu_ids); added the self-healing zone/center creation cts.clearing_sessions needs.
  • NGCHSubmissionWorkflow called a second, independent, never-working NGCH-file builder written against the inward data model — rewired to the real, tested one.
  • No dev HSM signer existed — NGCH signing crashed with 'NoneType has no attribute sign' the first time a real lot reached it.
  • Outward NGCH submission had no adapter method at all, on the dev stub or the real adapter — added, with the real adapter raising a clear NotImplementedError (no NPCI transport exists yet) instead of AttributeError.
  • Rate-limit middleware called call_next() twice on any route exception, turning every unhandled error anywhere in the API into a silent client-side hang instead of a 500.
  • Five RetryPolicy(maximum_attempts=None) settings across CTS workflows are invalid in this Temporal SDK (0 means unlimited) — each one made its workflow task fail forever.
Known open gap: the instrument-level status update (cheque_instruments.status → FILED, ngch_instrument_ref set) was fixed after this run completed — it is unit-tested but has not yet been exercised by a fresh live run. The lot and clearing-session rows above ARE the real, live post-fix state. Reconciliation and RRF generation are the next untested outward stages.
