Who sees rejections in production:
ops_manager / bank_it_admin → Admin console → Vault Upload Batches page → filter by status=PARTIAL or FAILED → see batch_id, rows_total, rows_processed, rows_failed, and first 50 error details.

ml_engineer / on-call → Temporal workflow history → activity result payload has full error list in memory → visible in Temporal Web UI for the workflow run.
Error record format (each entry in errors_json / result.errors):
{"row": 11, "error": "amount must be numeric, got 'NOT_A_NUMBER'"}
{"row": 21, "error": "Required column 'cheque_number' is empty or missing"}
{"row": 31, "error": "Invalid action 'DELETE'. Must be one of ['DEACTIVATE', 'INSERT_ONLY', 'UPDATE_ONLY', 'UPSERT']."}
{"row": 41, "error": "series_start (000100) must be ≤ series_end (000010)"} Row number = CSV row index (header = row 1, first data row = row 2). Exact bad value always included.
