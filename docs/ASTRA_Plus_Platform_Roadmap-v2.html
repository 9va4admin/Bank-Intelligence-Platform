Section 2

The Shared Engine

Eight platform components built once. Consumed by every module. The marginal cost of a new module is new business logic and a new external integration — not a new trust infrastructure.

Miniature Vault

CBS-isolated sub-5ms lookups for account state, signatures, mandates. CBS sees one call per cheque — not five.

Temporal Orchestration

Exactly-once, idempotent workflows with retries and compensating actions. No duplicate NGCH filings. No duplicate payments.

Reconciliation Engine

One engine normalises all external party return codes — cheque returns, regulatory rejections, payment rail statuses — into one internal taxonomy.

immudb Audit Store

Tamper-evident, Merkle-chained record of every action across every module. One audit trail. Cryptographically verifiable.

Identity & Access

Login · MFA (TOTP) · RBAC · SAML 2.0 / LDAP / Local. Shared auth layer — no module rebuilds authentication.

Notification Engine

WhatsApp Business API + Email (Postal). dispatcher.py routes alerts from any module — one infrastructure, many producers.

Explainable AI

SHAP-explainable fraud scoring · Vision LLM (Qwen2-VL) · OCR (GOT-OCR2) · Siamese signature network. Every AI decision has a human-readable rationale.

Sponsor Bank GTM

Banks landed via CTS are natural cross-sell targets for EJ, PRAMAAN, IBB. No new sales cycle — same CTO relationship.

CTS — Cheque Truncation & Clearing

Live
₹71L Cr Annual clearing value (FY25)
<600ms Agent decision wall-clock (p99)
0.000% IET breach rate (non-negotiable)
80% CBS call reduction via vaults

RBI's Phase 2 (Jan 2026) compressed the clearing window to T+3 hours with deemed-approval consequences. A cheque presented at 10:00 AM must be confirmed or returned by 1:00 PM. Miss the window — the bank pays, regardless of fraud. Manual review at scale is structurally impossible. An agent processes each inward cheque in under 600ms.

500 inward cheques → 500 agents spawn via Kafka fan-out → all run in parallel → entire batch done in <600ms wall-clock. The signature vault and PPS vault eliminate 80% of CBS calls from the critical path.

  • OCR (GOT-OCR2) + Qwen2-VL alteration forensics on all 3 cheque images
  • Signature verification: YOLO detection → Siamese network → vault lookup <5ms
  • Fraud scoring: XGBoost + LLM synthesis + SHAP before NGCH filing
  • IETWatchdogWorkflow: T-30s emergency filer, always-on, cannot be disabled

EJ Intelligence — ATM Electronic Journal

Prototype
2.5L+ ATMs in scope (RBI CCTV mandated)
5+ OEMs Zero standard format — root cause
48h Target dispute TAT (from 30–45 days)
₹100Cr+ Est. annual chargeback losses (industry)

Five OEM vendors — NCR Atleos, Diebold Nixdorf, Hyosung, AGS Transact, Euronet — generate EJ logs in proprietary formats with 3–5 firmware versions each active in the field. Rule-based parsers are a treadmill. AI is structurally the only viable solution.

The platform runs in two tiers. Tier 1 (immediate ROI): OEM-agnostic EJ normalisation → canonical hash-chained store → automated dispute evidence assembly → CCTV auto-retrieval → 48-hour resolution. Tier 2 (fraud ops): On-prem anomaly engine detecting skimming, cash trap, suspicious engineer access — requires Tier 1 data foundation first.

  • OEM classifier (confidence >0.95 to proceed) + active learning loop — model improves weekly
  • YugabyteDB hash-chained canonical store — SHA-256(prev_hash + all_fields), immutable once written
  • CCTV MCP adapter: millisecond-precision EJ timestamp → auto clip retrieval → evidence bundle
  • NPCI evidence API: canonical store exposed directly — no PDF submissions, no ops team involvement

PRAMAAN — Regulatory Reporting Orchestration

Blueprint-Ready
7 Regulatory report categories
4 tiers By penalty severity — Tier 1 zero-tolerance
₹100/day Statutory penalty on CIC/UCRF non-compliance

PRAMAAN (प्रमाण — proof, evidence) takes any regulator-mandated report through six stages: extract from CBS → transform to mandated schema → validate → transmit → reconcile the response → attest immutably. Seven categories: Credit Bureau (CIC/UCRF), Systemic Risk (CRILC), Registry (CKYCR/CERSAI), Unclaimed Assets (DEAF), AML/FIU-IND, Statistical/XBRL, and Instrument Clearing.

Nobody competes with a bank on internal regulatory tooling. PRAMAAN's market is uncontested by construction. Tier 1 (CRILC, FIU-IND STR/CTR) carries direct supervisory-action risk; Tier 2 (CIC/UCRF) carries ₹100/day compensation clauses with DQI visible to RBI monthly.

  • Exception Manager: normalises all rejection codes, starts statutory SLA clock automatically
  • DQI trending dashboard with half-yearly industry benchmark comparison
  • Mandated two-month top-management DQI report generated as a system byproduct
  • Root Cause Analysis auto-populated — no manual work

04

IBB — Integrated Business Banking

Decision Gate

IBB is ASTRA's entry into Connected Banking / API Corporate Banking — ERP-initiated payments (NEFT/RTGS/IMPS/UPI), real-time balances, unified reconciliation, Virtual Account Management, and BharatConnect-for-Business integration.

Every existing TSP (Cashfree, Yes Bank API Banking, ICICI Connected Banking) sits outside the bank's data boundary on cloud SaaS. On-prem Connected Banking is a genuine wedge for PSU/BFSI corporates under data-residency mandates. The same vault, Temporal engine, and reconciliation infrastructure transfer directly.

Build sequence

Tier A — Foundation

Corporate Payments Vault · ERP Connector Layer (read-only first) · mirrors CTS's trust-building sequence

Tier B — Core Differentiator

Idempotent payment initiation · Unified Reconciliation Engine · addresses treasury's #1 complaint (duplicate payments)

Tier C — Platform Moat

Payment Anomaly / Fraud Module · VAM · hard to replicate quickly

Tier D — Frontier

Trade Finance Document AI · needs Vision LLM hardened in CTS/EJ first
